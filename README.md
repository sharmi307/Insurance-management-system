# 🛡️ InsurancePro - Insurance Management System

## 📌 Project Overview

InsurancePro is a web-based Insurance Management System developed as part of a Web Development Internship Project.

The system provides a simple interface to manage insurance policies, claims, customers, agents, premium calculations, renewals, and reports.

## 🎯 Objectives

- Simplify insurance policy management.
- Organize customer and agent information.
- Record insurance claims.
- Calculate estimated insurance premiums.
- Provide a basic dashboard and reports.
- Demonstrate a login interface.

## ✨ Features

1. Dashboard
2. Policy Management
3. Claims Management
4. Customer Management
5. Agent Management
6. Premium Calculator
7. Policy Renewals
8. Reports
9. Login Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Navigate through the sections.
4. Add sample policies, customers, claims, and agents.
5. Test the premium calculator and reports.

## ⚠️ Limitations

This project is a front-end demonstration.

- Data is not permanently stored.
- Login is not connected to a real authentication system.
- Premium rates are for demonstration purposes only.
- No real insurance transactions are processed.
